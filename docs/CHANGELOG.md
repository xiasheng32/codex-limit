# 更新日志

本项目所有显著变更都记录在此文件中。版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)，日期为发布日期。

## [0.4.5] - 2026-10-16

### 变更
- 发布包文件白名单不再包含 9 个 `tests/*.test.ts`：测试仍全部保留在 GitHub 仓库，完整测试与类型检查请克隆仓库运行；解开 `.tgz` 的 `package/` 只用于安装试用。发布包从 22 个文件精简到 13 个（解包体积 336,667 B → 148,698 B），`extensions/index.ts`、`src/` 四个模块、`scripts/sync-autoload.ts`、`tsconfig.json`、双语 README 与 CHANGELOG、LICENSE 均保留，安装与 `/pi-codex`、`/fast` 入口不变。
- `npm run sync-autoload` 生成的单文件扩展头注释来源由本机目录名改为仓库地址 `xiasheng32/pi-codex`（仅注释，不影响生成逻辑与加载行为）。
- 双语 README 同步上述打包与测试说明，打包示例文件名更新为 `pi-codex-0.4.5.tgz`；包及锁文件根版本更新至 0.4.5。

## [0.4.4] - 2026-10-16

### 变更
- 详情面板正文信息行（额度条、重置倒计时、重置卡记录、提示行、Fast 两行与底部「更新于 HH:mm · 本机时区」）在面板内水平居中；标题栏与外框不变。
- 三个版块去掉 `──` 长分割线，改用居中的彩色短装饰标题：`─ 订阅额度 ─`（青）、`─ 重置卡 · 可用 N 张 ─`（紫）、`─ Fast ─`（绿），各有暗/亮两套配色，便于区分。
- 重置按钮改为三行方框按钮 `↻ 重置额度 · u`，去掉背景高亮；位置仍在重置卡明细后、Fast 之前并随正文滚动，`u` 仍为唯一入口且任意滚动位置有效，极窄终端退化为单行短标签；ready/处理中/不可用三种文案与配色不变。
- 双语 README 的打包下载名与当前版本同步为 0.4.4；包及锁文件根版本更新至 0.4.4。

## [0.4.3] - 2026-10-16

### 修复
- 同会话切换 provider 只暂停额度控制器，不再清除用卡未决锁及 HTTP 429 冷却；已发出消费请求的卡片不会因终态后回退的旧可用记录再次使用。
- 轮询或会话结算检测到退出登录时取消旧请求、清空账号缓存并隐藏 HUD；重新登录后轮询恢复。冷却和普通退避期间仍核对身份，切号不会继续显示旧账号数据，也不能绕过 429。
- Fast 使用薄原生 provider 适配层，在所有 payload 事件后依据实际请求捕获的 OAuth 凭据查询能力，避免切号竞态混用账号；分别保留原生 stream/streamSimple、OAuth、模型配置和 SSE/WebSocket 行为。
- 重置卡日期严格验证日历、闰年、时钟及时区；非法日期不会被 Date.parse 规范化后用于消费。
- 补充账号竞态、注销恢复、模型切换安全状态、终态回退、日期校验和原生 provider 选项回归；单文件部署及打包清单包含新适配层。

## [0.4.2] - 2026-10-15

### 变更
- 详情面板美化：标题含套餐，正文按额度 → 重置卡 → Fast 排列，保留完整额度及卡片记录。
- 重置按钮移至重置卡明细后，随正文滚动；任意滚动位置的 `u` 仍有效，选卡与二次确认不变。移除常驻用卡引导及同义提示，必要的不可用、忙碌和结果提示收归重置卡区。
- Fast 标题下仅两行：开启且能力支持时显示“已开启 · ×2.5”和“响应待确认 · 仅本会话”，关闭时显示“已关闭 · 标准”；能力受限使用短标签，服务端结果与开关独立，不再常驻模型、路由或长说明。
- 固定底栏为“更新于 HH:mm · 本机时区”，取 `lastSuccessAt` 并按本机时区显示；无值显示未知，刷新失败保留旧时间。
- 保留过期缓存、刷新及用卡安全逻辑；双语 README 与打包示例、包及锁文件根版本更新至 0.4.2，保留 v0.4.1 更名迁移说明。

## [0.4.1] - 2026-10-15

### 变更（破坏性）
- 插件由 `codex-limit` 更名为 `pi-codex`：包名、页脚状态键、单文件部署默认输出 `~/.pi/agent/extensions/pi-codex.ts`、测试文件名同步更名；GitHub 仓库更名为 `xiasheng32/pi-codex`（旧地址自动重定向）。
- 命令 `/codex-limit` 更名为 `/pi-codex`，旧命令不再保留；`/fast` 不变。

### 迁移
- 使用 pi-cc-extensions 自定义页脚的用户：把配置（如 `footerLine2Keys`）中的 `codex-limit` 改为 `pi-codex`，否则页脚不显示 Codex 状态。
- 单文件部署用户：删除或移出旧的 `~/.pi/agent/extensions/codex-limit.ts`，用 `npm run sync-autoload` 生成 `pi-codex.ts`，避免新旧副本重复加载。
- 已安装用户：运行 `pi update git:github.com/xiasheng32/pi-codex` 后重启 pi 或 `/reload`。

## [0.4.0] - 2026-10-15

### 新增
- 新增官方模型能力目录 `src/fast-catalog.ts`：查询 `GET /backend-api/codex/models?client_version=<Pi 版本>`，按目录判定模型 Fast 能力（支持/不支持/未知），不按模型名称猜测。
- 目录结果在内存缓存 5 分钟，查询失败退避 30 秒，账号切换隔离旧结果，离线模式不查询；目录缺失或查询失败显示能力未知。
- `/fast on` 先验证当前模型能力，仅目录明确支持才保存当前会话开关；能力未知、不支持或模型不适用时提示原因并保留原选择。
- `/codex-limit` 详情新增模型能力、请求档位与消耗说明（普通 Fast 按标准 2.5 倍）显示。
- 新增 `tests/catalog.test.ts` 与 `tests/host.test.ts`（Pi SDK `createAgentSession` + `ExtensionRunner` 全链路验证）。

### 变更
- Fast 请求路由改为目录门控：仅官方 `chatgpt.com` 端点、`openai-codex` provider、`openai-codex-responses` API 与 OAuth 订阅认证同时匹配的模型，开启且能力支持时设 `service_tier: "priority"`，关闭时显式设 `default`；其他请求不变。
- 页脚 Fast 后缀按请求路由显示 `· Fast` / `· Fast能力未知` / `· Fast不可用`，不再要求服务端确认；面板单独显示最近观察到的服务端档位。
- 保留的开启偏好遇到未知或不支持能力时不再请求 Fast；切换其他供应商或普通 OpenAI API 时隐藏整条 Codex 状态栏。
- 文档重构：中英 README 统一章节结构并精简，逐版本更新罗列迁入新增的中英 CHANGELOG。

### 修复
- Codex 订阅请求档位值恢复为订阅端点接受的 `priority`（v0.3.1 的修复经 revert 撤销后，随目录门控重新实现）。

- 新增 `src/fast-mode.ts` 及 `tests/fast-mode.test.ts`、`tests/extension.test.ts`、`tests/transport.test.ts`。

### 变更
